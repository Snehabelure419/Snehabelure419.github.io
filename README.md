## 🚀 Run Locally

You can run the portfolio on your computer by following these steps.

**1. Clone the repository**

```bash
git clone https://github.com/Snehabelure419/SnehaBelure419.github.io.git
```

**2. Open the project folder**

```bash
cd SnehaBelure419.github.io
```

**3. Launch the website**

Open `index.html` in your browser, or open the folder in Visual Studio Code and use the Live Server extension.

No backend setup is required for a static portfolio website.
